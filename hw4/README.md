# Homework 4: Numerical Analysis of Stellar Lifetime

This folder contains the materials for Homework 4 of **Modern Astronomy**, Spring 2026, Peking University.

The main part of this homework is a numerical analysis project on stellar lifetime. The analysis explores how stellar properties relate to the expected lifetime of a star, using Python-based computation and visualization.

## Main Analysis

- `stellar_lifetime_analysis.ipynb`: Main notebook for the numerical analysis of stellar lifetime.
- `stellar_lifetime_plots.pdf`: Output plots generated from the analysis.
- `homework4_written_response.ipynb`: Full written response for the homework.
