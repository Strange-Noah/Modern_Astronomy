# Homework 3: Hubble Redshift Analysis and JWST Image Annotation

This folder contains the materials for Homework 3 of **Modern Astronomy**, Spring 2026, Peking University.

The homework consists of two main parts. The first part focuses on Hubble’s redshift-distance relation, and the second part focuses on annotating a JWST image and explaining the astronomical structures visible in the image.

## Hubble Redshift Analysis

The `hubble_redshift/` folder contains the materials related to Hubble’s redshift-distance relation.

- `hubble_1929_redshift_paper.pdf`: Original Hubble paper used as the historical reference.
- `hubble_1929_data.csv`: Raw data used for the analysis.
- `hubble_analysis.py`: Python script for plotting and fitting the data.
- `hubble_plot.png`: Output figure generated from the analysis.

This part of the homework revisits one of the foundational observational results in modern cosmology: the relationship between galaxy distance and recession velocity.

## JWST Image Annotation

The `jwst_image_annotation/` folder contains the materials related to the JWST image annotation task.

- `jwst_raw.jpg`: Original JWST image.
- `jwst_annotated.jpeg`: Annotated version of the JWST image.
- `jwst_annotation.md`: Markdown version of the annotation explanation.
- `jwst_annotation.pdf`: PDF version of the annotation explanation.

This part of the homework focuses on visual interpretation and science communication, using annotation to identify and explain features in a JWST image.
