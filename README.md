# Modern Astronomy Coursework Portfolio

This repository collects selected coursework, data analysis exercises, and presentation projects from **Modern Astronomy**, Spring 2026, Peking University.

The work covers astronomical data analysis, scientific writing, numerical computation, and science communication projects related to modern observational astronomy.

## Highlights

### Homework 2: Pleiades Cluster Analysis

This assignment focuses on identifying and visualizing the Pleiades star cluster using Gaia data. The analysis uses astrometric features such as proper motion and distance to separate candidate cluster members from the surrounding stellar field. It provides a compact example of how modern astronomical catalogs can be explored computationally.

### Homework 3: JWST and Hubble Data Analysis

This section combines science writing on the James Webb Space Telescope with a data analysis exercise based on Hubble’s 1929 velocity-distance data. The Hubble-related work reproduces the basic idea behind the velocity-distance relation and compares the fitted result with a modern reference value.

### Homework 4: Numerical Analysis of Stellar Lifetime

Homework 4 is organized around a numerical analysis project on stellar lifetime. Using Python-based computation and visualization, the project explores the relationship between stellar mass and lifetime, and presents the resulting plots alongside the full written response.

### Project 1: The Nice Model

Project 1 is a self-selected science communication project on the Nice Model, a theoretical framework for understanding the dynamical evolution of the Solar System. The project focuses on explaining how interactions among the giant planets may have shaped the architecture of the Solar System.

### Project 2: Planet Hunters TESS

Project 2 is based on the citizen science platform Planet Hunters TESS. In addition to discussing human visual inspection in citizen science, the project introduces algorithmic transit detection as a comparison point. The central question is how human pattern recognition and automated detection methods can complement each other in the search for exoplanets.
