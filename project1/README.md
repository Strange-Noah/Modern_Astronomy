# Project 1: The Nice Model

This folder contains the materials for Project 1 of **Modern Astronomy**, Spring 2026, Peking University.

Project 1 was a self-selected science communication project. I chose the **Nice Model**, a theoretical framework that explains how the early dynamical evolution of the giant planets may have shaped the current architecture of the Solar System. The project focuses on presenting the scientific motivation, core mechanism, and broader implications of the Nice Model in an accessible way.
