# Homework 2: Pleiades Cluster Analysis with Gaia Data

This folder contains the materials for Homework 2 of **Modern Astronomy**, Spring 2026, Peking University.

The main focus of this homework is the identification and visualization of the Pleiades star cluster using Gaia data. The analysis uses astrometric and photometric information, including proper motion, distance, and color-magnitude features, to explore how the cluster can be distinguished from surrounding field stars.
